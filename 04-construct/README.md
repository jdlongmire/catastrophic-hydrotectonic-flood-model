# 04-construct/

How this programme reasons and how work on it gets done.

| File | What |
|---|---|
| [`methodology.md`](methodology.md) | the Popper/Lakatos apparatus — progressive vs degenerating, the circularity check |
| [`methods.md`](methods.md) | 20 numbered working rules, most of them born from a specific recorded failure |
| [`means/agents/`](means/agents/) | four agent profiles — QA, Peer-Review, Red-Team, Computation |
| [`means/ops/`](means/ops/) | session lifecycle scripts, link tooling |
| [`means/sessions/`](means/sessions/) | the session journal |

**On the 5M+1 naming.** The construct surface is nominally 5M+1 (mission, mind, morals, memory, methods, plus means). Only the surfaces that genuinely exist are named here; `methodology.md` and `methods.md` keep their own filenames rather than being renamed into a set with three empty placeholders beside them. See ADR-HTF-META-0001, deviation 3.
