# decisions/

Programme-level decision records — calls about the research itself, as distinct from structural calls about the repository, which live in [`../00-meta-model/`](../00-meta-model/).

**Empty as of 2026-08-18.** The programme's decisions to date are recorded in two places that predate this directory and are not back-filled into it: dated rows in [`appraisal.md`](../03-solutions-baseline/3.3-prediction/appraisal.md), and [`dev-notes/`](../dev-notes/) entries carrying an explicit Status. Both remain valid records.

Use this directory when a call is durable, contested, or would otherwise be re-litigated — the kind of thing a future session would waste time re-deriving.
