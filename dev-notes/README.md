# Dev Notes

Working discussion on model refinements — technical back-and-forth, half-resolved questions, pushback that hasn't yet settled into a formal position. Deliberately outside the numbered Lakatos tiers (`00`–`04`): those are the structured apparatus and its current settled content; this is the raw discussion that feeds it, same relationship [`../research/`](../research/) has to the rest of the repo, but for ongoing refinement rather than the founding transcript.

**What goes here:** a dated note per discussion thread — a claim gets checked, a distinction gets drawn, a question stays open pending an answer. Written as the exchange actually happened, including where it *isn't* resolved yet.

**What doesn't stay here:** once a discussion produces a real conclusion — a number, a corrected claim, a resolved ambiguity — that conclusion is promoted into the belt (`02-theory/`), the hard core (`01-hypothesis/`), or logged in the appraisal (`03-prediction/appraisal.md`), with a pointer back to the note it came from. A dev-note that never graduates anywhere is either still open or wasn't worth capturing.

**Filename convention:** `YYYYMMDD-topic-slug.md` — no separators in the date, so plain alphabetical directory listing sorts in chronological order.
