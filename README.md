# Hydrotectonic Flood Model

A Lakatosian research programme reconstructing a historical, hydrotectonic global Flood — catastrophic plate reorganization coupled to deep-mantle water transport — within a Genesis-consistent chronology, without requiring the observational corpus to entail a deep-time history.

| | |
|---|---|
| **Core commitment** | No deep-time entailment; Genesis records real historical events (creation, Fall, Flood); the Flood was a real historical global catastrophe; natural law is stable from the close of the catastrophe forward |
| **Chronology** (belt — calibrated, not revealed; see [hard-core.md](1-hypothesis/hard-core.md)) | ~50 kyr creation-to-Fall gap (est.) · ~1 yr Flood · ~6,000 yr post-Flood to present |
| **Mechanism** (belt) | Impact-triggered catastrophic plate reorganization + deep-mantle water transport via hydrous wadsleyite/ringwoodite |
| **Status** | Stood up 2026-08-16. **Unappraised** — zero theoretically progressive steps taken; three degenerating accommodation moves recorded in the initial research; one gating open problem (transient mantle viscosity, 5–6 orders of magnitude below any value in mainstream geodynamics) blocks the critical path |

## Honest standing

This programme has an articulated hard core and an articulated positive heuristic. It does not yet have a claim that forbids anything. The initial research's own internal arithmetic and cited empirical anchors check out on independent review; its three sequential attempts to fix a catastrophic-phase stratigraphic boundary do not — each is a purely accommodative belt revision, and the programme records that plainly rather than presenting the search as progress. The single largest open problem is physical, not stratigraphic: the transient mantle viscosity the mechanism requires has never been shown achievable. See [`3-prediction/appraisal.md`](3-prediction/appraisal.md) for the full audit and [`3-prediction/discriminators.md`](3-prediction/discriminators.md) for what would change the verdict.

There is no mechanized claims registry yet (see [`0-program-methods/METHODOLOGY.md`](0-program-methods/METHODOLOGY.md)); this programme stands up prose-first and mechanizes once there's enough claim volume to justify it.
